# Source Code

This directory contains all the source code for the Babylon.js dungeon crawler game.

## Directory Structure

- **core/** - Core game engine functionality (engine initialization, game loop, scene management)
- **systems/** - Game systems (input handling, physics, collision detection, AI, inventory)
- **entities/** - Game entities (player, enemies, items, props)
- **scenes/** - Game scenes (main menu, gameplay, pause menu, game over)
- **ui/** - User interface components (HUD, menus, dialogs)
- **utils/** - Utility functions and helpers (math utilities, data loaders, helpers)
