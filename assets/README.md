# Assets

This directory contains all game assets including models, textures, sounds, and materials.

## Directory Structure

- **models/** - 3D models for characters, enemies, dungeon pieces, items, and props
- **textures/** - Texture files for walls, floors, characters, items, and UI elements
- **sounds/** - Audio files for music, sound effects, and ambient sounds
- **materials/** - Material definitions for Babylon.js (PBR materials, shaders)
